Installer sur mon téléphone

Une fois cette page hébergée gratuitement (ex. GitHub Pages, Netlify Drop ou Vercel), vous pouvez l'installer comme une vraie application mobile sans passer par un store :

🍎 Sur iPhone (Safari)
  1. Ouvrez cette page dans Safari.
  2. Appuyez sur le bouton Partager (carré avec flèche vers le haut) en bas de l'écran.
  3. Faites défiler et appuyez sur « Sur l'écran d'accueil ».
🤖 Sur Android (Chrome)
  1. Ouvrez cette page dans Google Chrome.
  2. Appuyez sur le menu ⋮ en haut à droite.
  3. Appuyez sur « Ajouter à l'écran d'accueil » ou « Installer l'application ».
